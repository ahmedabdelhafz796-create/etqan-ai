The standard

What "production-hardened" actually means

Every guarantee below is enforced automatically before release. A template that fails any of them is never published — that's a build gate, not a promise.

Replay protectionDuplicate webhooks cause no duplicate side effects. Event-id dedupe with TTL pruning, and no external database to provision.
Retry on every network callThree attempts with backoff. Enforced default-deny: any node not known to run locally must retry.
Failures are routed, never silentChecked per node, not once per file. A declared error output that leads nowhere fails the build.
One config nodeEverything you edit is in one place at the top of the flow. Secrets live in credentials, never in the file.
Zero embedded credentialsScanned automatically for live keys and for credential ids pinned from the author's own account.
Documentation on the canvasExplained next to the node it applies to — not in a PDF you won't read while something is broken.
Cloud and self-hosted behave identicallyHMAC goes through the built-in Crypto node, never require('crypto') — which works on Cloud and throws on a default self-hosted install.
Questions

Before you buy

Do I need to be technical?

No. Each template has one node you edit — ⚙️ Config, the first thing in the flow. Everything else is documented on the canvas next to the thing it explains. Most take 10–15 minutes, and the Setup Checker tells you if you've missed anything before you go live.

What do I need to run these?

An n8n account — Cloud or self-hosted, both work identically. An SMTP account for email (a free tier is plenty). The AI templates need your own API key from Anthropic or OpenAI; everything else runs without one.

Which payment platforms are supported?

Stripe, PayPal, Lemon Squeezy, Gumroad, Paddle and NOWPayments out of the box — all six normalise into one internal format. If your platform can send a webhook when a payment completes, it will almost certainly work.

How is this different from the free templates on GitHub?

There are thousands of free n8n workflows and many are good. The difference is what happens when things go wrong: replayed webhooks, temporary API failures, silent send errors. These handle all three, and they're tested behaviourally — the workflows are actually executed against adversarial input rather than eyeballed. Try the free one and judge for yourself.

Can I use these for client work?

Yes. Set them up for clients and charge what you like. What you can't do is resell or redistribute the workflow files themselves, or include them in a template pack you sell. Full terms ship with every download.

What if something doesn't work?

Send your n8n version, the name of the node that failed, and the error text — that usually resolves it in one reply. The Setup Checker's output often contains the answer already. And the 14-day refund stands regardless.
